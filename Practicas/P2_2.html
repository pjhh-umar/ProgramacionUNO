Solicita N entero entre 0 y 10000. Parte de 3 y agrega N correcciones alternantes de la fórmula indicada. Imprime aproximación y error absoluto frente a math.pi. Compara con Leibniz utilizando el mismo número total de términos: N+1.

Ejemplos o comprobaciones:

N = 0 → 3.
N = 2 → 3.1333333333.

Observación: Reto opcional. T_N = 3 + suma de (-1)**(k+1) * 4/((2*k)*(2*k+1)*(2*k+2)), para k=1,…,N. No omitas el signo alternante.

Práctica

Aproximación del seno

Solicita x real en radianes con -π ≤ x ≤ π y N entero entre 1 y 20. Calcula la suma de N términos indicada y muestra el error absoluto respecto de math.sin(x), que se utiliza solo para verificar.

Ejemplos o comprobaciones:

x = 0, N = 1 → 0.
x = 1, N = 2 → 0.8333333333.

Observación: Reto opcional. S_N = suma de (-1)**k * x**(2*k+1)/(2*k+1)!, para k=0,…,N-1. Se define m! como el producto de 1 a m y 0!=1; puedes utilizar math.factorial().
